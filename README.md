# 🎂 ほしいものクイズ

母の60歳の誕生日プレゼントを決めるための、アキネーター風の質問アプリです。

「お菓子でいいよ」と言われてしまうけれど、遠方でなかなか会えず好みもよくわからない。
それなら本人に2択・3択をポチポチ押してもらって、
その答えから欲しいものを当てにいこう、という趣旨のものです。

- 質問は **8〜11問**。答えに応じて次の質問が変わります
- 最後に候補が3つ出て、本人が1つ選びます
- 「LINEで送る」を押すと、選んだ品物・ひとこと・全回答が入ったリンクが息子に届きます
- サーバーは不要です。HTMLとCSSとJavaScriptだけで動きます

## 使い方

1. 下の手順で公開して、URLを母に送る
2. 母がポチポチ答える
3. 母が「LINEで送る」を押す → 結果のリンクが届く
4. そのリンクを開くと、選ばれた品・次点・好みのキーワード・全回答が見られる

## 公開のしかた（GitHub Pages）

いちばん手軽なのは、リポジトリの設定から公開する方法です。

1. GitHub のリポジトリ → **Settings** → **Pages**
2. **Source** を `Deploy from a branch` にする
3. Branch に公開したいブランチ（`main` など）、フォルダは `/ (root)` を選んで **Save**
4. 数分待つと `https://<ユーザー名>.github.io/happy-birthday-gift/` で開けます

GitHub Actions で公開したい場合は `.github/workflows/pages.yml` を用意してあります。
Settings → Pages の **Source** を `GitHub Actions` にすると、`main` への push で自動的に公開されます。
別のブランチを試しに公開したいときは、Actions タブから **Deploy to GitHub Pages** を
手動実行（Run workflow）してください。

```bash
npx http-server -p 8000 .

```

## しくみ

プレゼント候補にはそれぞれ「タグ」がついています（`sweets`, `appliance`, `together` など）。

1. 質問に答えるたびに、選択肢が持つタグの点数が加算される
   （マイナスの点数もあります。「服は自分で選びたい」なら `fashion: -3`）
2. プレゼントの点数 = そのプレゼントが持つタグの点数の合計
   ÷ √(タグの数)（タグが多い候補が有利になりすぎないようにするため）
3. **次の質問は、いまの上位候補の点差がいちばん大きく開く質問を選ぶ**

3番目がアキネーター的なところで、「答えを聞いたときにいちばん情報が増える質問」を
毎回えらび直しています。だから食べもの寄りの人には食べものを絞る質問が、
体験寄りの人には出かけ先の質問が飛んでくる、という動きになります。

8問を過ぎた時点で1位と2位が十分離れていたら、そこで打ち切ります（最大11問）。

### 内容を変えるには

`assets/data.js` だけ触れば変えられます。

```js
// プレゼントを足す
{ id: 'my_gift', emoji: '🎁', name: '贈りたいもの',
  budget: '1万円くらい',
  note: '結果画面に出る説明文',
  tags: ['food', 'consumable', 'budget_low'] },

// 質問を足す
{ id: 'q_new', text: '聞きたいこと',
  choices: [
    { emoji: '🅰️', label: '選択肢A', tags: { food: 3, keepsake: -2 } },
    { emoji: '🅱️', label: '選択肢B', tags: { experience: 3 } }
  ] },
```

タグは新しく作っても構いません。結果画面に日本語で出したいときは、
`data.js` の先頭の `TAG_LABELS` に追加してください。

## プライバシー

- 回答はサーバーに送られません。ブラウザの中だけで完結します
- 途中まで答えた内容は端末の `localStorage` に保存され、「前回のつづきから」で再開できます
- 息子に届くのは、本人が「送る」を押したときだけ。中身はリンクの `#` 以降に
  詰め込まれているので、途中のサーバーには渡りません

## 動作確認

4通りの回答パターン（お菓子派・体験派・実用家電派・家族派）で最後まで答えてみて、
妥当な候補が出ること・結果リンクが正しく復元されることを確かめるテストがあります。

```bash
npm install -D playwright && npx playwright install chromium   # 初回のみ
node test/e2e.mjs
```
